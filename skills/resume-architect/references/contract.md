# Application Boundary

Resume Architect receives only the packet assembled by the application: a saved profile, curated workspace-owned evidence and handoffs, designated template metadata, and an optional explicitly selected opportunity. It returns a structured proposal; the host validates every visible claim and persists only valid output.

It cannot browse folders, read files, call tools, contact networks, select a workspace, save drafts, or render a PDF. Resume Coach is the downstream independent reviewer; Architect does not call it.
