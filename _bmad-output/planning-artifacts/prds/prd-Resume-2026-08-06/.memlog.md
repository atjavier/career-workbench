- (decision) PRD scope preserves manual-only refreshes, permitted sources only, private single-user use, truthful material generation, and no application automation as non-negotiable user requirements.
- (decision) Fit labels are specified as transparent evidence guidance using matches, gaps, seniority, location, and freshness, not hiring predictions.
- (decision) Google Sheets tracking via user-authorized minimum-scope OAuth must cover jobs, material versions, stages, follow-ups, and multiple interview rounds.
- (assumption) Web single-user surface, local authoritative application record, fit-label implementation method, document format, provider, and OAuth mechanics are deferred to architecture.
- (change) Reviewer gate completed; PRD now makes fit-rubric consistency an explicit architecture decision and preserves unset success-metric targets as an open product-owner decision.
- (event) PRD finalized
- (change by user) Re-scope job discovery to manual opportunity capture as the reliable default: user supplies an external posting URL and copied job-description text; the app structures it locally, preserves attribution, and supports fit, Resume Coach, handoff, and tracking.
- (change by user) Remove universal automated job-board retrieval, source configurations, permitted-source setup, and refresh runs from the MVP workflow. Retain any future approved company/ATS feeds only as optional post-MVP enhancements.
- (decision by user) Keep the product local-first, evidence-led, truthfulness-preserving, and external-application-handoff-only while simplifying its primary user journey.
- (event) User approved the Manual Opportunity Capture sprint change proposal on 2026-08-24.
